# 회사 PC 확인 체크리스트 (Tool A v1.5 · 트렌드 리포트 v0.1)

이 코드는 회사 밖(리눅스)에서 시험 데이터로 끝까지 실행·빌드까지 확인했다.
엑셀 화면 모양과 Windows exe 동작은 회사 PC에서 아래 순서로 확인한다.

## 0. 준비
- `pip install matplotlib` (v1.5에서 새로 필요) → 각 폴더에서 spec으로 빌드 (README 참고)
- Tool A·트렌드 리포트 exe를 같은 폴더에 둔다 → 누적 DB를 같이 씀

## 1. Tool A v1.5 (실데이터 1일치)
- [ ] 같은 입력으로 v1.4.1과 v1.5를 돌려 `Daily_BU설비데이터` 시트 값이 같은지 (기존 결과 불변)
- [ ] `공정능력_BU_WU` 시트의 Ppk가 양식 19행 S(WU)·T(BU) CPK 값과 같은지
- [ ] Cp/Cpk를 Minitab(USL 100을 '경계'가 아닌 일반 규격으로 입력)과 비교 — 소수 둘째 자리 일치
- [ ] LD 모델(G10·GEN) LMK6 파일 선택 → 'LD 모델' 자동 체크 + 노란 안내, 결과 BU `N/A (LD 모델)`
- [ ] `BU_History_DB.xlsx` 생성 → 같은 파일 다시 실행 시 로그 '0행 추가, 이미 있는 N행 건너뜀'
- [ ] 파일을 고르지 않고 실행 → 경고 후 실행 버튼이 정상으로 돌아오는지 (v1.4.1 버그 수정)

## 2. 트렌드 리포트 v0.1
- [ ] ① 실제 이벤트 2~3개 등록 (모델 칸: WINE처럼 모델명 또는 VDA129처럼 코드 일부)
- [ ] ② 과거 `Daily data 통합정리_*.xlsx` 폴더 선택 → 측정일 확인
      (파일명 날짜 = Tool 실행일이므로 측정일과 다르면 '측정일 직접 지정')
- [ ] 경고(기간 밖·겹침) 행은 '이벤트 변경'으로 지정하거나 그대로 두고 적재
- [ ] ③ 리포트 생성 → 이벤트 요약 값이 각 이벤트의 공정능력 시트와 맞는지

## 알려진 제약 (v0.1)
- 과거 파일에는 측정 시각이 없어, 그 데이터의 군내 σ는 LotID 순서로 계산된다 (v1.5 이후 적재분은 측정 시각 순)
- 그래프는 그림(A안). 트렌드 리포트를 엑셀 차트(B안)로 바꾸려면 `common/charts.py`만 교체
- 박스플롯을 엑셀 차트로 만들 경우, 표 필터로 행을 숨기면 수염 위치가 어긋남 → 이벤트는 생성 화면에서 선택
