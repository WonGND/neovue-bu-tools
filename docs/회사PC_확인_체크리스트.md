# 회사 PC 확인 체크리스트 (Tool A v1.5.3 · 트렌드 리포트 v0.6 · Tool B v0.6.2)

이 코드는 회사 밖(리눅스)에서 시험 데이터로 끝까지 실행·빌드까지 확인했다.
엑셀 화면 모양과 Windows exe 동작(특히 파일 끌어다 놓기)은 회사 PC에서 아래 순서로 확인한다.

## 0. 준비
- `python -m pip install matplotlib tkinterdnd2` (matplotlib = v1.5부터, tkinterdnd2 = 트렌드 v0.2 끌어다 놓기)
- 각 폴더에서 `python -m PyInstaller --noconfirm <spec>`으로 빌드 (README 참고)
- 빌드 성공 확인: 마지막 줄 `Build complete!` → exe는 명령을 실행한 폴더의 `dist`에 생김
- 누적 DB는 `문서\BU_Tools\BU_History_DB.xlsx` 하나를 두 툴이 같이 씀 (exe를 같은 폴더에 둘 필요 없음)

## 알려진 제약
- 과거 파일에는 측정 시각이 없어, 그 데이터의 군내 σ는 LotID 순서로 계산된다 (v1.5 이후 Tool A 적재분은 측정 시각 순)
- 과거 파일의 측정일은 파일명 날짜(= Tool 실행일). 실제 측정일과 다르면 파일 추가 창에서 더블클릭으로 바꾼다 (미시 분석에만 영향)
- 그래프는 그림(A안). 트렌드 리포트를 엑셀 차트(B안)로 바꾸려면 `common/charts.py`만 교체
- 끌어다 놓기는 리눅스에서 라이브러리 불러오기·연결까지만 확인했다. 실제 마우스 드롭은 회사 PC에서 확인
